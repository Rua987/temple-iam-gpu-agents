# archive/

Files moved out of the project root to keep the repo focused on the GPU
monitoring / thermal tuning tool. Nothing here is required to run it.

- **docs/** — old/redundant READMEs, quick-start variants, status reports,
  merge summaries, and migration notes that duplicated or predated the main
  [README](../README.md).
- **logs/** — captured console/debug output (`debug_log.txt`, model output
  dumps, etc.). Pure noise; kept only for reference.
- **off-topic/** — launchers and assets unrelated to GPU optimization
  (Elden Ring "ODIN" agent, Cheat Engine, Obsidian installers, etc.).

To restore a file, just move it back to the project root.
