# 🎮 Temple IAM - Guide Ultra Simple pour Débutants

## 🌟 **C'est quoi Temple IAM?**

Un programme qui **optimise automatiquement** ton GPU NVIDIA pendant que tu joues!

- ✅ **Aucune configuration** nécessaire
- ✅ **Détecte automatiquement** n'importe quel jeu
- ✅ **Améliore les performances** (+10-30% FPS)
- ✅ **Garde ton GPU au frais** (température optimale)
- ✅ **Fonctionne sur TOUS les GPU NVIDIA** (GTX, RTX)

---

## ⚡ **Démarrage en 3 Étapes**

### **Étape 1: Télécharge le Code**

**Option A: Avec Git** (Recommandé)
```bash
git clone https://github.com/Rua987/temple-iam-gpu-agents.git
cd temple-iam-gpu-agents
```

**Option B: Sans Git**
1. Va sur: https://github.com/Rua987/temple-iam-gpu-agents
2. Click sur le bouton vert "Code"
3. Click sur "Download ZIP"
4. Extrais le ZIP
5. Ouvre le dossier

### **Étape 2: Installe Python**

**Si tu n'as pas Python:**
1. Va sur: https://www.python.org/downloads/
2. Télécharge Python 3.10 ou plus récent
3. **IMPORTANT**: Coche la case "Add Python to PATH" pendant l'installation!

### **Étape 3: Lance le Programme**

**Windows (Double-click):**
```
Double-click sur: START_HERE.bat
```

**Ou en ligne de commande:**
```bash
# Installe les dépendances (une seule fois)
pip install -r requirements_gpu.txt

# Lance le programme
python run_universal_monitor_v2.py
```

## 🆘 **Problèmes?**

### **"Python n'est pas reconnu..."**
➜ Réinstalle Python et coche "Add to PATH"

### **"GPU non détecté"**
➜ Assure-toi d'avoir les drivers NVIDIA installés
➜ Teste avec: `nvidia-smi` dans le terminal

### **"Module not found"**
➜ Lance: `pip install -r requirements_gpu.txt`

### **Besoin d'aide?**
➜ Ouvre une Issue sur GitHub: https://github.com/Rua987/temple-iam-gpu-agents/issues
